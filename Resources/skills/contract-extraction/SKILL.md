# 合同字段抽取

## 读取
1. 用 `read_file` 读合同全文（PDF 很长时用 `pages` 分段读，例如 `1-5`、`6-10`）。扫描页会自动送文档识别（OCR）：
   - 每页以 `<!-- Page N -->` 或 `<!-- Page N（扫描件 OCR） -->` 开头，据此记录页码；
   - 页末的「> ⚠ 需核对」列出两档识别不一致、或被印章遮挡的内容，涉及的字段必须标「需核对」；
   - `【印章 / 图片中的文字（OCR）：…】` 是印章里识别出的文字；`【图片区域…未识别出文字…】` 表示该处有印章 / 签名但读不出。
2. 如果结果提示「文档识别不可用」，直接把原因告诉用户（例如需要连 VPN），不要凭空编造合同内容。

## 抽取字段（没有的写「未约定 / 未找到」，不要猜）
| 字段 | 说明 |
|---|---|
| 合同名称、合同编号 | |
| 甲方 / 乙方（及其他方） | 全称、法定代表人、地址、联系人、电话 |
| 标的 / 服务内容 | 一句话概括 |
| 合同金额 | 总价、单价、币种、是否含税、税率；大小写金额都写出并核对是否一致 |
| 付款方式与节点 | 分期比例、条件、期限 |
| 签订日期、生效日期 | |
| 合同期限 | 起止日期、续约 / 自动续期条款 |
| 交付 / 验收 | 时间、标准 |
| 违约责任 | 违约金比例 / 金额、赔偿上限 |
| 解除 / 终止条件 | |
| 保密、知识产权 | 有无、期限 |
| 争议解决 | 仲裁 / 诉讼、地点、适用法律 |
| 盖章与签字 | 每一方是否盖章（印章文字）、是否签字、签署日期；读不出的写「有印章 / 签名，文字未识别，请对照原页」 |
| 附件清单 | |

## 输出
1. 一张 Markdown 表：`字段 | 内容 | 页码 | 状态`。状态取「✓」或「⚠ 需核对（原因）」：
   - 页末「需核对」里出现过的值；
   - 只有一档识别到的金额 / 日期 / 编号；
   - 大小写金额不一致、日期前后矛盾、合计与明细对不上。
2. 「风险提示」：3–6 条，例如无违约金上限、自动续期、单方解除权、付款前置条件，每条带页码。
3. 结尾固定提醒：「扫描件由文字识别得到，金额、日期、账号请对照原件核对（工具卡上的「原页对照」可逐页比对）。」
4. 用户要台账 / 多份合同汇总时，每份合同一行写成 CSV 或 Excel，用 `write_file` 保存到 `outputs/合同台账_<日期>.csv`，列名与上表字段一致，另加「来源文件」「需核对项数」两列。

## 要求
- 所有内容必须来自 read_file 读到的原文，不补全、不推测；印章、手写内容尤其不能猜。
- 引用原文时保留原样（包括 OCR 可能的错字），并在状态里注明。
