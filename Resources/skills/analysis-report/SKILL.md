# 分析报告

结构（使用用户的语言）：
1. **摘要**：3 条以内最重要结论，每条带数字。
2. **数据与口径**：数据来源（表、行数、时间范围）、指标定义、过滤规则。
3. **关键指标**：表格列出核心 KPI 及同比/环比。
4. **发现**：每个发现 = 结论 + 支撑数据 + 可能原因（标明是推测）。
5. **建议**：可执行、对应发现。
6. **附录**：使用的 SQL。

要求：所有数字必须来自本会话实际执行的查询；用 write_file 保存到 `exports/报告_<主题>_<日期>.md`；需要可视化时同时用 dashboard_create 生成看板并在报告中引用。
