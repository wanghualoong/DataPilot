# DataPilot 用户手册

## 复制
回答整条可跨段落、列表、表格连续选中复制（表格复制为制表符分隔，可直接粘贴进 Excel）；回答下方的复制按钮复制 Markdown 原文。

## 安装
1. 打开 `DataPilot-<版本>.dmg`，把 DataPilot 拖到“应用程序”。
2. 首次打开若提示无法验证开发者：系统设置 → 隐私与安全性 → “仍要打开”。（或终端执行 `xattr -dr com.apple.quarantine /Applications/DataPilot.app`）

## 首次配置
启动后出现向导：
1. 选择预设（自定义 / DKU AI Gateway (NetID) / 本地 Ollama）或直接填 Base URL 与 API Key。
   - DKU 用户：选 DKU 预设后点 **“登录并选择 Key…”**，用 Duke NetID 登录，从自己的 Key 列表里选一个即可（也可以新建一个 DataPilot 专用 Key），不用手动复制。之后在 设置 → 模型服务 中也能随时重新登录、换 Key。侧栏左下角的 **⚙︎ 齿轮菜单** 里有“登录并选择 Key…”和“设置…”（类似 Codex）：选网关 → 登录 → 选 Key → 弹出模型勾选列表（可修改服务名称；默认只勾选一个结尾为 local 的本地模型），点“添加”完成。还没配置模型时，主页和空白会话页也会显示这个按钮。
2. 点“连接并获取模型”，向导自动推荐主对话模型（优先结尾为 local 的模型，如 `qwen3.8-27b-local`，并标为「本地」）和快速模型。完成时只添加所选模型和这个 local 模型。不需要 Embedding / Rerank 模型。
3. 完成。之后可在 **设置（⌘,）** 中修改：
   - 模型服务：多个 Provider；
   - 模型角色：为每个角色选模型，点“测试”自动探测工具调用/推理能力；“能力…”可手动调整上下文窗口、思考参数等；
   - 索引与检索：查看关键词索引条数（检索 = 关键词全文检索 + grep）；
   - 扩展：浏览器域名、MCP 服务器、Computer Use；
   - 通用：界面语言（中/英）、回复语言、小表阈值、压缩阈值、长期记忆开关、网络代理（跟随系统 / 直连 / 自定义，可测试连接）。

## 中途插话与 /btw
- Agent 运行时可以直接输入并回车「插话」：消息显示为「排队中」，Agent 执行完当前工具后会读到并调整做法。送达前可点 ✕ 撤回，或输入框为空时按 ↑ 取回修改。想立刻打断请点停止（⌘.）。
- `/btw 问题`：顺便问一句，比如“/btw 刚才的会员口径是什么？”。带当前对话上下文、不调用工具、不写入对话，运行中也能用，回答显示在紫色卡片里。

## 切换模型
配置了多个模型服务商时，输入框下方的模型菜单和 `/model` 都是两级：先选服务商，再选模型。`/model` 里按 ⌫ 或 Esc 回到服务商列表；也可以直接输入模型名搜索所有服务商。只有一个服务商时直接列出模型。

## 分析数据
1. ⌘N 新建会话，把 Excel/CSV 拖进窗口（或点 📎）。
2. 直接提问，如“各大区销售额和同比？”。Agent 会导入数据、查看结构与表间关系、写 SQL / Python，并给出结论。
3. 工具卡片可展开查看 SQL、代码与原始输出；SQL 结果正确时点 👍，以后同类问题会参考。
4. 输入框下方：
   - **计划 / 询问 / 自动**：复杂任务先用“计划”，Agent 只读探查后给出计划卡，批准后执行；
   - 模型切换、**思考**开关、**联网**总开关（默认关；关闭时任何工具都不能上网，Agent 需要联网时会弹卡请你开启）；
   - 右侧显示上下文占用。
5. 右侧检查器（⌥⌘I）：数据（表、关系、预览）· 看板 · 浏览器 · 记忆 · 任务 · 文件。

## 连接数据库
1. 右侧「数据」页 →「数据库连接」→「新建…」，选类型，填主机、端口、库名、账号、密码（建议只读账号）。SQLite / DuckDB 文件需放在项目文件夹里。
2. 密码只存在钥匙串里，模型看不到；DataPilot 只为这个端口开放网络，联网开关保持关闭即可。
3. 「…」菜单 →「选择表抽取到本地…」：把明细拉到本地分析（推荐）；之后「刷新已抽取的表」可重新拉取，依赖它们的派生表会自动重建。
4. 也可以直接问：“看看销售库里有哪些表”“查一下生产库上个月的订单数”，Agent 会用 db_schema / db_query 只读查询。
5. SQL 结果卡片的「更多」：保存到「我的查询」、格式化、执行计划、查看全部行。

## / 命令
在输入框键入 `/` 弹出命令面板（↑↓ 选择、回车执行、Tab 补全、Esc 关闭）：
| 命令 | 作用 |
|---|---|
| `/plan` `/ask` `/auto` | 切换模式（`/plan 问题` 直接以计划模式提问） |
| `/init` | 扫描数据，生成 `DATAPILOT.md`（项目说明） |
| `/dashboard [要求]` | 把本会话的分析组合成交互式看板 |
| `/skills` | 二级列表：选择一个 skill 执行（含 Codex / Claude Code 的 skills，标签显示来源） |
| `/<skill 名> [补充说明]` | 直接调用某个 skill |
| `/skill-new`（也可输入 `/skill_save`、`/save_skill`） | 用内置 skill-creator 把一套流程保存成新 skill |
| `/export [md\|html\|jsonl]` | 导出对话 |
| `/btw 问题` | 顺便问一句（不调用工具、不写入对话） |
| `/status` `/model` `/compact` `/rewind` `/new` `/memory` `/browser` `/mcp` `/help` | 状态、切换模型、压缩、回退、新会话、记忆页、浏览器、MCP 状态、帮助 |
| `/context` | 上下文占用明细：系统说明、工具定义、记忆、对话、工具结果各占多少 token，还剩多少 |
| `/fork` | 复制当前会话（对话 + 笔记；非项目会话连工作区数据一起复制），在副本里试另一种思路，不影响原会话 |
| `/review [重点]` | 让模型复核上一轮分析：口径、空值、重复计数、JOIN 放大、结论与数据是否一致 |
| `/doctor` | 一键自检：Python 运行时、数据内核、API Key、主模型连通、网络 / 代理、Chrome、数据目录、磁盘、MCP |
| `/remember 内容` | 写一条记忆（项目会话写入项目记忆，否则写入个人记忆），以后分析自动参考 |
| `/copy` | 复制上一条回答 |
| `/permissions` `/settings` `/todos` | 打开 设置→权限、设置→通用、任务面板 |

命令名中 `_` 与 `-` 等价、不区分大小写；输错时会提示最接近的命令。

外部 skills：设置 → 扩展 → Skills，默认读取 `~/.codex/skills`、`~/.codex/skills/.system`、`~/.claude/skills`（只读；同名时内置和用户 skill 优先）。

## 项目
- 侧栏底部“新建项目（选择文件夹）”。对话、数据库、看板保存在该文件夹的 `.datapilot/` 中，产出写到 `outputs/`，原始文件只读。
- 同一项目的会话共享导入的表；每个会话的 Python 变量互相独立。
- 检查器“文件”页列出项目文件，点 🔍 即可让 Agent 分析该文件。详见 `docs/12-projects.md`。

## 导出对话
工具栏“导出对话”（或 `/export`）：Markdown（含 SQL、代码、结果表）、离线 HTML、原始 JSONL 记录。项目会话默认保存到 `outputs/`。

## BI 看板
- 说“做一个销售看板，可按大区和品类筛选”。看板在检查器“看板”页打开。
- 顶部筛选器；卡片右上角切换维度 / 指标 / 图表类型；点击图形联动筛选其它组件；▦ 查看数据表。
- 导出：离线可交互的 HTML、规格 JSON、PNG。
- 聊天里每张图下方有「加入看板」；看板页为空时会列出本会话图表，可“一键生成看板”或“让 Agent 设计看板”。
- 图表卡片标题栏的 **ƒx**：加参考线（平均 / 中位数 / 最大最小）、细分维度、增长率 / 累计 / 占比 / 移动平均、切换汇总方式。也可以直接对 Agent 说“按年度画工会人数，加一条年平均线”。
- 项目里每个对话有自己的看板；看板页右上角「全部」可查看项目内其他对话的看板。数据（DuckDB 表）在项目内共享。
- 数据页 / 看板页若提示内核错误，点「重启内核」即可恢复。
- 项目右键菜单：「从侧栏移除（保留文件）」只是不在侧栏显示；「删除项目数据（不保留，可重新开始）…」会把 `.datapilot/`（数据库、该项目所有对话、看板）、`outputs/` 和 `DATAPILOT.md` 移到废纸篓（可恢复），你自己的 CSV / Excel 不动，之后可重新打开该文件夹从头开始。
- 项目文件夹里的数据文件有变化时，下一次提问会先自动处理：已导入的文件被修改，会自动重新导入替换；新增的文件和被删除的文件会先弹卡片问你（导入新文件 / 删除对应的表）。
- 同一项目的多个对话可以同时工作：一个对话在导入大文件或跑代码时，另一个对话的查询、数据页和看板刷新都能立即返回。只有两个对话都要**执行 Python 代码**时才需要排队。
- 数据页顶部会列出运行较久的任务（含其他对话的），例如「「对话 X」 正在导入 · Sales.csv（32s）」，点旁边的停止按钮只停这一个任务。
- 按聊天里的「停止」只停本对话的任务，不会打断同项目其他对话。
- 修改：直接说“把品类占比换成柱状图”“加一个按渠道的趋势图”。

## 记忆
- 右侧「记忆」页的四类（长期记忆、历史会话、数据集、Q-SQL）每行都有 ✏️ 编辑和 🗑 删除（右键菜单也有）；删除前会确认。底部可“清空操作记录”。
- “记住：金额用万元”→ 立即生效；纠正口径（“收入要剔除退款”）也会被记住，并绑定到该数据集。
- 重复的行为（如反复把饼图换成柱状图）会形成“待确认”的习惯，在检查器“记忆”页确认、编辑或删除。
- “记忆”页分三栏：长期记忆（已生效/待确认/已归档）、历史会话（双击打开）、数据集（指纹、出现过的会话、口径条数），顶部显示各类计数。还没有记忆时会说明记忆如何形成，也可以手动添加。
- 下次上传同类报表时，会自动带出上次的口径与历史分析。
- 工具栏 👁 可查看每轮注入给模型的记忆与上下文。设置中可关闭长期记忆。

## 工具栏按钮（聊天页右上角）
- 👁 **显示注入上下文**：显示 / 隐藏每轮自动注入给模型的上下文（日期、相关记忆、会话笔记、数据表状态），显示在对应消息上方；还没注入过时会提示。
- ⤡ **压缩上下文**（同 `/compact`）：把较早的对话总结成摘要、释放模型上下文；对话还很短时会提示“没有需要压缩的内容”。Agent 运行中也可以点：会排队，在当前这一步完成后立即压缩。
- 导出对话、检查器开关。

## 会话与回退
- 会话自动保存，重开即恢复（表、DataFrame、看板都在）。
- 右键自己的消息 →“回退到此消息之前”：工作区与对话同时恢复到该时刻。
- ⌘⇧K 手动压缩上下文；⌘. 停止。

## 浏览器与电脑控制
- 让 Agent“打开某网页抓取表格”时，检查器“浏览器”页实时显示，需要登录可先自己登录。
- Computer Use 默认关闭；开启后每步需批准，⌃⌥⎋ 急停。

## 数据位置
`~/Library/Application Support/DataPilot/`（设置 → 通用 → 在 Finder 中显示）。未归档会话的工作区在 `sessions/<id>/workspace/`；项目会话在 `<项目>/.datapilot/`。

## 联网搜索
打开「联网」后直接问需要最新信息的问题（如“今天昆山天气”），Agent 会用本机 Chrome 搜 Google 再读原文并注明来源。没装 Chrome 时会提示一键下载 Chrome for Testing；Google 要求人机验证时会弹出 Chrome 窗口，完成一次即可。

## 外观（深色 / 浅色）
设置 → 通用 → 「外观」，或左下角齿轮菜单 → 外观：**跟随系统**（默认，系统切换时界面立即跟着变）、**浅色**、**深色**。主界面、看板、聊天图表、ER 图和窗口标题栏一起切换；导出的 HTML 按当前外观生成。这个选择只保存在本机。
