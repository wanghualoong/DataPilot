# ADR-0008 · 四种审批模式、说明符规则与本地模式

日期：2026-11-09　状态：已采纳

## 决策
- 审批模式 计划 / 询问 / 自动 / 完全访问，与“联网”开关正交（联网由开关决定，见 ADR-0007）。
- 规则采用 Claude Code `Tool(specifier)` 语法，deny > ask > allow；“总是允许”记录带说明符的规则（域名、命令前缀），而不是整个工具。
- 拒绝可附反馈文本（Claude Code 的 Tab 补充说明 / Codex 的 rejection）。
- 本地模式在唯一的 LLM 客户端工厂 `AgentServices.client(for:)` 处拦截，App 侧直接建客户端的测试按钮单独拦截。

## 理由
单一拦截点保证后台任务（记忆抽取、压缩、标题）也不会把数据发到云端；说明符规则避免“总是允许 web_fetch”这种过宽授权。
