# ADR 0005：项目 = 用户文件夹，状态放在 .datapilot/
- 决策：项目状态（会话转录、共享 DuckDB、看板）写在 `<项目>/.datapilot/`；原始文件在沙箱内只读，产出写 `outputs/`；一个项目一个内核进程、一个共享数据库，Python 变量按会话 namespace 隔离。
- 备选：(a) 状态集中放在 Application Support，项目只记录路径——迁移和备份不方便；(b) 每个会话一个数据库——项目内的会话要重复导入，口径不一致。
- 代价：项目会话无法用 APFS 快照回退数据库（共享状态），只回退上下文并提示用户；`.datapilot/` 默认 gitignore，避免把数据库提交进仓库。
- 参考：Codex 的项目/工作目录与 AGENTS.md；用户在 2026-11-08 的选择（存放在 .datapilot、原始文件只读、项目共享数据库）。
